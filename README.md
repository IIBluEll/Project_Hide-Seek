# ISOLATION PROTOCOL

> 소음과 시야를 관리하며 폐쇄 시설을 탈출하는 1인칭 잠입 생존 공포 게임

NHN 공모전 참가를 목표로 3인이 제작한 Unity 프로젝트입니다. 플레이어는 전투 없이 시설을 탐색하고, 발전기를 복구하는 동안 자신이 만든 소음과 추격 AI의 압박을 함께 관리해야 합니다.

[WebGL로 플레이](https://iibluell.github.io/Project_Hide-Seek/) · [상세 시스템 및 기술 구조](./TECHNICAL_OVERVIEW.md)

## 프로젝트 소개

전원이 차단된 폐쇄 시설에는 시야와 소리를 근거로 플레이어를 추적하는 Chase AI가 배회합니다. 플레이어는 이동 속도와 자세를 조절하고, 은신처와 디코이를 활용해 AI의 판단을 흔들면서 활성 발전기 3개를 복구해야 합니다.

모든 발전기를 복구하면 탈출 경로가 열립니다. AI에게 붙잡히면 즉시 게임 오버가 되며, 제한된 정보만으로 위험을 예측하고 목표를 완수하는 것이 핵심입니다.

| 항목 | 내용 |
| --- | --- |
| 장르 | 1인칭 생존 공포, 잠입, 추격 |
| 플레이 방식 | 싱글 플레이 |
| 목표 플레이 시간 | 1회 약 10~15분 |
| 핵심 목표 | 활성 발전기 3개 복구 후 탈출 |
| 전투 | 없음 |
| 난이도 | Easy / Normal / Hard |
| 플랫폼 | WebGL |

## 핵심 경험

- **목표가 만드는 위험:** 발전기를 수리하려면 한곳에 머물러야 하며, 작동음과 QTE 실패음은 AI가 조사할 새로운 단서가 됩니다.
- **근거를 사용하는 AI:** Chase AI는 플레이어의 위치를 항상 알지 못합니다. 직접 본 위치, 들은 소리, 마지막으로 남은 증거를 바탕으로 조사하고 수색합니다.
- **긴장과 회복의 반복:** Director 역할의 Master AI가 추격 AI의 활동과 이탈 시점을 조절해 압박 구간과 탐색 구간을 만듭니다.
- **달라지는 이동 동선:** 맵에 배치된 후보 지점 중 일부 발전기만 선택되므로 플레이할 때마다 탐색 경로가 달라집니다.
- **정보를 듣는 공포:** AI의 발소리, 울음소리, Vent 소리와 단계적으로 변하는 음악이 화면 밖의 위험을 전달합니다.

## 게임 플레이

1. 시설을 탐색해 이번 플레이에 활성화된 발전기를 찾습니다.
2. 걷기, 달리기, 앉기를 선택하며 이동 속도와 발생 소음을 조절합니다.
3. AI가 접근하면 시야를 끊고 은신하거나, 디코이를 던져 다른 위치에 소음 증거를 만듭니다.
4. 발전기를 수리하면서 무작위로 등장하는 QTE를 수행합니다.
5. 세 발전기를 모두 복구한 뒤 활성화된 탈출구에 도달합니다.

## 주요 시스템

### 증거 기반 Chase AI

Chase AI는 시각과 청각 감지, 기억, 증거 선택, 상태 머신, NavMesh 이동을 분리한 구조로 동작합니다. `DORMANT`, `PATROL`, `INVESTIGATE`, `CHASE`, `ATTACK`, `SEARCH`, `RETREAT` 상태를 오가며 직접 감지한 정보와 마지막 증거의 위치를 기준으로 행동합니다.

일반 순찰 지점과 은신처 조사 지점을 구분해, 근거 없이 플레이어가 숨은 장소를 바로 확인하지 않도록 설계했습니다. 시야를 잃으면 마지막 목격 위치와 이동 방향을 중심으로 제한된 수색을 수행합니다.

### Master AI와 긴장도 조절

Master AI는 개별 추격 행동을 직접 결정하지 않고 전체 페이싱을 담당합니다. 최근 압박 수준을 나타내는 `GlobalStress`를 이용해 Chase AI의 활동, 이탈, 재등장 흐름을 조절하고, 필요할 때 정확한 좌표가 아닌 Zone 단위의 힌트만 전달합니다.

발전기 진행에 따른 장기 난이도는 Chase AI의 `Anger`로 별도 관리합니다. 이를 통해 한 번의 추격이 끝난 뒤에는 회복 구간을 제공하면서도 게임 후반의 압박은 점진적으로 높일 수 있습니다.

### 발전기와 QTE

발전기는 미리 배치된 후보 중 Zone이 겹치지 않도록 우선 선택됩니다. 플레이어가 `E`를 누르는 동안 수리가 진행되고, 수리 도중 발생하는 QTE의 성공 여부가 진행도와 소음에 영향을 줍니다. 수리를 중단하면 짧은 유예 후 진행도가 감소하므로 주변을 살피는 판단과 목표 달성 속도 사이에 긴장이 생깁니다.

### 은신과 디코이

플레이어는 앉아서 소음을 줄이고 책상 아래와 같은 지정 은신처를 사용할 수 있습니다. 디코이는 충돌 위치에 새로운 소음 이벤트를 발생시켜 AI의 조사 목표를 바꾸는 도구이며, AI를 즉시 무력화하는 장비는 아닙니다.

### 사운드와 연출

AI 상태와 공간 관계에 따라 BGM은 `AMBIENT`, `TENSION`, `CHASE`, `ENDING` 단계로 전환됩니다. 발전기 완료 후에는 탈출구가 열리고 목표 실루엣이 표시되며, 사망과 탈출은 각각 컷신과 결과 흐름으로 이어집니다.

## 조작법

키보드와 마우스를 기준으로 합니다.

| 입력 | 동작 |
| --- | --- |
| `WASD` / 방향키 | 이동 |
| 마우스 이동 | 시점 회전 |
| `Left Shift` 유지 | 달리기 |
| `C` | 앉기 / 일어서기 |
| `E` | 상호작용 |
| `E` 유지 | 발전기 수리 |
| `Space` | 발전기 QTE 입력 |
| 마우스 왼쪽 버튼 유지 후 놓기 | 디코이 조준·충전 후 투척 |
| 마우스 오른쪽 버튼 | 디코이 조준 취소 |
| `H` | 미완료 발전기 위치 표시 |

## 프로젝트 실행

### 준비 사항

- Unity Hub
- Unity Editor `6000.3.20f1`
- Git
- WebGL 빌드 시 WebGL Build Support 모듈

### 실행 순서

```bash
git clone https://github.com/IIBluEll/Project_Hide-Seek.git
cd Project_Hide-Seek
```

1. Unity Hub에서 저장소 루트 폴더를 엽니다.
2. Package Manager가 의존성을 복원할 때까지 기다립니다.
3. `Assets/01_Main/01_Scene/TitleScene.unity`를 엽니다.
4. Unity Editor의 Play 버튼을 누릅니다.

게임의 씬 흐름은 다음과 같습니다.

```text
TitleScene → LoadingScene → InGame_Map
     └────→ TutorialScene
```
