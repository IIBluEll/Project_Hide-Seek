## GDD 문구 반영만 남은 것 (5건)

방향이 확정됐고 구현도 그 방향이다. **회의에서는 누가 언제 고칠지만 정하면 된다.**

| 위치 | 현재 GDD 서술 | 바꿀 내용 | 근거 |
| --- | --- | --- | --- |
| 14.1 | 음악 상태에 `SAFE` 포함 | **삭제.** 네 단계로 정리 | 구현은 4단계다. `SAFE`는 `AMBIENT`와 조건이 겹쳐 구분되는 연출이 안 나온다. 2026-08-03 기획 확인에서 제거 결정 |
| 14.1 | `TENSION` = 같은 Zone **또는 인접 Zone** | **"같은 Zone"으로 좁힌다** | 음악은 AI와의 거리를 알려주는 정보 채널이다(3.1). 범위가 넓어질수록 신호 대비 노이즈가 커진다. `AIWorldZone`에 인접 판정 API도 없다 |
| 14.1 | `ENDING` = 발전기 완료 **+ 탈출 장치 활성화** | **"모든 발전기 완료"로 확정.** "탈출 장치 생기면 다시 정한다" 단서 삭제 | `EscapeDoorLock`·`EscapeTrigger` 구현 후 재검토해 현행 유지로 확정. 발전기를 다 고친 순간이 곧 문 잠금이 풀리는 순간이라 실질적으로 같은 시점이고, 옮기면 수정과 재검증만 는다 |
| 14.2 | 발전기 필수 효과음에 "**전기 스파크**" | **삭제.** 7.4는 그대로 두고, 12장 환경 스파크는 별개 항목임을 명시 | 스파크는 VFX로 확정했고 전용 사운드를 만들지 않는다. 7.4의 스파크는 "붉은 피드백"과 나란히 있고 소리는 같은 줄의 "큰 소음"이 맡으므로 원래 시각 연출로 읽힌다. 14.2가 이를 *효과음* 목록에 넣은 것이 혼선의 원인이었다 |
| 13.1 | 인게임 HUD에 **위치 표시 없음** | **추가.** ①키 입력으로 발동해 정해진 시간 뒤 자동 종료 ②게임당 사용 횟수가 제한된 소모성 능력 ③완료된 발전기는 표시 안 함 | 이미 구현되어 동작하는데 근거 조항이 없다. 13.1이 "AI 위치 표시는 사용하지 않는다"고 못박고 있어, 대상이 AI가 아니라 목표물이고 횟수가 제한된다는 점을 적어야 그 원칙과 구분된다. 구체적 수치는 19장 미정 사항으로 두고 플레이 테스트로 정한다 |

`74f432b`에서 Chase AI 사운드 서술(발소리 구분, Pitch 변형, 3D `SFX` 출력, `NoiseProvider` 재발행 금지)은 이미 14.2에 반영됐다. 추가 요청 없다.

## D-1. BGM 상태 정의의 나머지 둘

**결정할 것:** GDD 14.1의 두 조건을 삭제할지.

| 쟁점 | GDD 14.1 | 현재 코드 |
| --- | --- | --- |
| `TENSION` 추가 조건 | 소음을 **조사 중**일 때도 | 조사 여부를 보지 않음 |
| `AMBIENT` 조건 | "**긴장도가 낮은**" | `GlobalStress` 미사용 |

**의견: 둘 다 삭제를 권한다.**

조사 조건은 인접 Zone과 GDD 같은 문장에서 나왔고 반대 근거도 같다. Director 힌트는 부정확한 Zone을 가리키므로(9.4), 조사 중이라는 이유로 긴장 음악을 켜면 AI가 맵 반대편을 뒤지는 동안에도 음악이 유지된다. 위치 정보를 주는 대신 노이즈만 준다. 조사 중이면서 같은 Zone이면 위치 조건으로 이미 켜진다.

`GlobalStress`는 Director의 활동·휴식 주기를 담당하는 값이라 음악 판정에 끌어 쓰면 AI가 멀어져도 긴장이 유지되어 위치 정보와 어긋난다.

**막히는 것:** 없다. 다만 고치지 않으면 기준이 계속 두 개로 남는다.

## D-2. 웹 빌드 오디오 예산

**결정할 것:** 오디오 총 다운로드 용량 상한과 BGM 음질을 어디까지 낮출지.

- **WebGL은 `Streaming`을 지원하지 않는다.** 클립을 통째로 받아야 재생이 시작된다
- BGM 4개만으로 약 54MB. 오디오 에셋 전체는 107개 261MB이고 실제 연결된 건 9개뿐이다
- ENDING 클립만 24bit인데 최종 인코딩이 AAC라 이점 없이 용량만 1.5배다

**의견:** 앰비언스는 고주파가 적어 샘플레이트를 낮춰도 체감 손실이 작다. 모노 변환은 용량이 절반이 되지만 호러 앰비언스의 공간감을 해치므로 BGM에는 권하지 않는다. 구체적 권장 설정은 `STATUS.md` 2장에 있다.

**막히는 것:** 상한이 없으면 임포트 설정을 정할 수 없고 초기 로딩 시간이 통제되지 않는다.

## D-3. 볼륨 설정 인터페이스

**결정할 것:** 사운드가 노출할 훅의 형태와 설정 값 저장 주체.

GDD 13.2는 전체 볼륨·배경 음악·효과음 셋을 요구한다. 13장이 UI 챕터이므로 **설정 화면과 저장은 UI 담당 영역**이다. AudioMixer에 `MasterVolume` / `BgmVolume` / `SfxVolume`은 이미 노출되어 있다.

**의견:** 사운드는 "이 세 값을 적용하는 훅"까지만 제공하고 설정 화면과 저장 데이터는 UI 담당이 소유한다. QTE 키를 UI 담당 키 설정 시스템으로 넘기기로 한 것과 같은 방식이다.

**되돌릴 위험:** 합의 없이 사운드 쪽에서 저장까지 만들면 UI 담당 작업과 중복된다.

## D-4. `ChaseAISound` 배선 담당

**결정할 것:** 클립 선정과 믹서 그룹 연결을 누가 언제 할지.

구현은 끝났으나 `ChaseAI.prefab`에서 `_outputMixerGroup`이 비어 있고 클립 배열 12개가 모두 비어 **소리가 전혀 나지 않는다.**

**의견:** 믹서 그룹 연결은 사운드 공용 구조에 속하므로 사운드 측이 할 수 있다. 발소리·울음소리 클립 선정은 AI 연출 의도를 아는 담당자 몫이다.

## D-5. 심장 소리 (예고)

플레이어와 Chase AI의 거리에 따라 심장 소리 속도가 변하는 기능. 사운드 담당 범위지만 설계 논의 전이다.

논의할 지점 셋 — 거리 기준(직선 / 경로 / Zone), BGM `TENSION`과 역할이 겹치지 않게 하는 방법, 이 소리가 AI에게 들리는 소음이 아니라 플레이어 전용 연출이라는 점의 명시.
